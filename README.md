# Anshul Panchal · Engineering Portfolio

Live site: https://anshulseam53-wq.github.io/

A single-page engineering portfolio with interactive models: CYPHER OS, WooZOOM MK1, AXYS Labs,
PitPRO, ISS SSEP Mission 22, AP3X, SpikePRO, VEDA and DBOT. `index.html` holds the page, its styles
and scripts; `img/` and `media/` hold figures, meshes and one video. Three.js loads from jsDelivr
and fonts from Google Fonts.
